# Habit Tracker

+ Habit Tracker es un programa de control de habitos pensado para ayudarte a mejorar y mantener tus habitos

## Caracteristicas principales
* **Caracteristica 1** Registra y controla los habitos diarios
* **Caracteristica 2** Contiene una base de datos donde se almancena los registros de seguimiento de los habitos, un calenadrio y una interfaz grafica con menú
* **Cacarteristica 3** 

## Tecnologías y Herramientas
* **Lenguaje** Java
* **Interfaz** Java Swing
* **Base de datos** SQLite
* **IDE** Apache NetBeans
